# No Clue
## By ( Hazoro - Vii - AboEl5yr )

A game that mixes between both the "Mist" area in silksonng, and the popular anomalies-spotting game, Exit 8 (出口八)

# Game Flow
- The player gets to test their limits and ego by inputting the number of rooms they want to beat (to create more challenge), between 5 and 20
- You enter a room with 5 doors, only one of them is right
- Interact with the cat and understand its hints for the correct door !
- If u enter the wrong one, you start all over!!
- wait for a surprise once u win ^^ (EMOTIONAL)

In EQUINOX CAT WE BELIEVE, YOUR GUIDE TO THE EXIT !!

# Controls
- Movement : Arrows & WASD
- Interaction : Enter, Space, E
